# ÁguaPrajá

Água em galão por assinatura para as cidades mineradoras do Pará, com piloto em **Canaã dos Carajás**.

| Pasta | O que é |
|---|---|
| `simulador/` | Página de validação: simulador de consumo e cadastro de interesse (Next.js). Veja `simulador/README.md`. |
| `validacao/` | Roteiro de entrevistas com distribuidoras e famílias. |

Na Vercel, ao importar este repositório, use **Root Directory = `simulador`**.
